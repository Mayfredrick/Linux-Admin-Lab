## Scripts

### hello.sh
Prints a greeting along with the current date and user.

### variables.sh
Demonstrates the use of Bash variables.

### userinput.sh
Accepts user input and displays it.

### diskcheck.sh
Checks disk usage and reports whether usage exceeds a defined threshold.

### functions.sh
Shows how to organize Bash code into reusable functions.

### system_report.sh
Generates a system information report containing:
- Hostname
- IP address
- Current user
- Kernel version
- Operating system
- Uptime
- Memory usage
- Disk usage
