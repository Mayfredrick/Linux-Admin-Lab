## Objectives
In this lab the main objective is to learn and master the commands used on some Unix operating systems.
To achieve the objective of this lab, I decided to use the ubuntu server which strictly uses cli unlike 
other systems like Ubuntu desktop which has graphical user interface.

## Commands Executed
-sudo apt update,upgrade,dist-upgrade and autoremove.
-lsb_release -a
-mkdir and nano text editor
-ls,ls -la, cd /, cd ~ ,cd /etc ,cd /home, cd /var
-whoami,hostname,date,uptime, free -h, df -h, ip addr and ip route

## What I learnt
In this lab I observed the differences between different commands and what they store. For instance, if you compare the the /etc and /home
the /etc contains a lot of directories and files as compared to the /home which stores what the user as created.
It is also easy to see all the route information and ip addresses of the interfaces using ip route and ip addr command.
