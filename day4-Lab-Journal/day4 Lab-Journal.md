## Lessons Learned

\-The line #!/bin/bash is to tell operating system which interpreter should be used to run a script when it executed directly.

\-The use of chmod +x is to change the regular file into executable file so the script can be executed successful.

\-A variable in bash script is a named container that stores data so it can be recalled or reused during script execution.

\-Using automation in this lab show casing how  important it is in reducing time doing repetitive tasks. It is also helpful in minimizing downtime.
